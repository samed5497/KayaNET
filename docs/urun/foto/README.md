# KayaNET gerçek cihaz fotoğrafları

Bu klasöre yalnızca gerçek cihazdan çekilmiş fotoğraflar konur (uydurma/üretilmiş görsel yok). Hedef: 1–3 adet.

Dosya adları (web ajanı bu adları bekler):
1. `kayanet-cihaz.jpg` — Pi 4B + kasa/fan/adaptör, çalışır halde
2. `kayanet-hotspot-telefon.jpg` — telefonda KayaNET Wi-Fi'ı ve ana sayfa açık
3. `kayanet-kullanim.jpg` — (isteğe bağlı) ekran/HDMI modu veya sahada kullanım

Öneri: yatay, doğal ışık, min. 1600 px genişlik, kişisel bilgi (MAC, IP listesi, parola) görünmesin. Eklenince `git add docs/urun/foto && git commit && git push`, ardından web ajanı Prompt'taki "FOTO BÖLÜMÜ" adımını uygular.
